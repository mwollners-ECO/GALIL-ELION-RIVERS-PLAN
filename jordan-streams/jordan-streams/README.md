# מפת העבודה – נחלי מקורות הירדן

עמוד הצוות. הכתובת אחרי הפרסום:
https://mwollners-eco.github.io/ECO.URBANISM/jordan-streams/

- `index.html` – העמוד.
- `files/bg`, `files/ch-0` … `files/ch-12` – תיקיות החומרים. קובץ שמועלה לכאן (Add file → Upload files) מופיע בעמוד בתיקייה המתאימה.
- `files/structure` – מבנה מסמך שלב 2 (PDF ו-Word).
- `links.json` – קישורים נוספים. כל שורה: `{"folder":"4","title":"שם החומר","url":"https://…","cat":"אחר"}`. folder הוא מספר הפרק, או `bg` לחומרי רקע.

סימוני V ברשימת המשימות נשמרים בדפדפן של כל אחד בלבד.
